② 叙事链

在 PIE — 源头：指下去的手指

六千年前，PIE 人有一个指示词干 *de-。这不是空间介词——这是一个指示词，和英语的 the、this、that 属于同一类语法家族。它的功能不是描述方向，而是用手指着某个位置——尤其是手指往下指。「那里」「下面」「往下的那边」——*de- 是从手势语言固化到语法中的化石。[Wikt-PIE]

*de- 和另一个 PIE 指示词干 *ad-（朝向）在语义上构成互补——*ad- 是"朝目标指"，*de- 是"朝下指"。两者在 PIE 中都没有明确的"方向义"——它们只是「指」的动作。方向义是后代语言自己加上去的：拉丁人把 *de- 理解为向下（指下面→往下），日耳曼人把 *de- 理解为朝向目标（指那边→往那边→to）。

同一个 PIE 指示词 *de-，一个后代是 de-（向下前缀），另一个后代是 to（朝向介词）。两人六千年前是同一个人用手指着——没人知道它指的方向到底是"下"还是"往"。[Etym]

在罗马 — 向下、离开、彻底：拉丁人的三层编码

罗马人继承了 PIE *de-，发展出拉丁语前缀 dē-——三义面并行（和 dis- 一样，但三义面的分布不同）。

线一：向下——物理空间的原义。 这是从 PIE "往下指"直接延续下来的空间义，在拉丁语中最活跃：

  • dēscendere = dē- + scandere（爬）→ 向下爬 → descend（下降）。scandere 的本义是"登上"——罗马人用 scandere 指从下往上爬，加 de- 就变成了从上往下走。descend 是 scandere 在方向上的完全逆转——和 return（转回去）属于同一个"反转"结构。
  • dēclīnāre = dē- + clināre（弯、倾斜）→ 向下弯 → decline（下降、婉拒）。身体向下弯——在罗马文化中，弯腰有两种解读：一是物理解释（山坡往下斜、数量往下降），二是社交解释（身体向下弯 = 拒绝但不伤对方的面子 → decline an invitation）。decline 同时承载了这两个语义面。
  • dēpendēre = dē- + pendēre（悬挂）→ 挂在下面 → depend（依靠）。pendēre 的物理画面是一根树枝上挂着的果子——果子的整个存在取决于那根树枝。depend 的"依赖"语义从这段画面中直接推出来——你就是那个果子。

线二：离开/去除——向下→从表面脱离。 什么东西往下掉的时候，它离开了原来的位置：

  • dēcidere = dē- + caedere（切、砍）→ 把多余选项砍掉 → decide（决定）。decide 的字面画面是战士在战场上把不属于自己的敌人的头砍掉——留下的就是决定。caedere 不是温柔的"切"——它是一刀两端、不可逆的动作。决定一旦砍了就接不回去了。
  • dēpartīre = dē- + partīre（分开）→ 从群体中分出去 → depart（离开）。

线三：彻底——向下走到底。 这个义面和 con- 的"彻底"（聚力→彻底）来自完全不同的物理经验。con- 是"聚到一处→全力以赴"，dē- 是"往下走到底→完全做完"：

  • dēlēre = dē- + lēre（抹去、涂抹——可能与 linere 同源）→ 完全抹去 → delete（删除）。注意：delete 不是从 delete key 来时才开始存在的——dēlēre 在拉丁语中的本义是把墙上的字完全擦掉——从墙面往下刮到光滑为止。
  • dēservīre = dē- + servīre（服务）→ 服务做到位 → deserve（应得）。servus 是罗马的奴隶身份——servīre 是奴隶为主人做事。dēservīre 是奴隶把服务做到了极致——尽了全力、应得报酬。今天的 deserve 不再需要「奴隶」的比喻——但"做够了就该得"的语义逻辑一丝未变。[Etym]

这三个义面中，「向下」最古老、「彻底」次之、「离开」最晚——和 dis- 不同，de- 的三义面的时间层级是可排的。[Etym]

在希腊 — 无

PIE *de- 在希腊语中没有发展为前缀。希腊人表达"向下"用的是 kata-（κατά = 向下、根据、反对——和 de- 的语义有重合但不同源）。kata- 的后代词汇（catalogue, catastrophe, category）在英语中很常见——但在比较 de- 和 kata- 的时候不要被义面重合迷惑：de- 来自 *de-（指示词），kata- 来自 *km̥t（沿着、向下），两个完全不同的根。[Etym]

在日耳曼 — to：de- 的反向孪生

这是 de- 故事里最值得记住的细节。

PIE *de- 进入原始日耳曼语，经过元音变换后变成 *tō（d→t 是格林定律清化），古英语 tō，现代英语 to。to 是英语里使用频率最高的三个介词之一——at、of、to。而 to 和 de- 是同源词——你每天说 to go，那个 to 和 decide 的 de- 六千年前是同一个 PIE 词。

但方向反了。de- = 从上面下来；to = 朝目标去。同一个 PIE 指示词，为什么后代的方向反了？答案在 PIE 时代——*de- 的意思不是「向下」也不是「朝向」，而是「指着某个位置」。后人（拉丁人和日耳曼人）各取了这个手势的一半：

  • 拉丁人取了「指下面」的一半 → 向下。dēscendere = 从爬下来的方向。
  • 日耳曼人取了「指那边」的一半 → 朝目标去。tō gān = 向那边走→ to go。

这不是反义——是同一只手，指了两个不同的方向。PIE 的指示词系本身就模糊——一个手指可以朝很多方向指，具体指哪个方向，留给后代去固化。拉丁选了向下，日耳曼选了朝向。[Etym]

在法国 — des- 混乱：当 de- 和 dis- 穿上同一件衣服

诺曼征服后，拉丁 de- 词和 dis- 词同时通过法语大量进入英语——但法语把它们穿成了同一件衣服：des-。

古法语中，拉丁 dē- 和 dis- 因为发音趋同（元音变短、e 和 i 在非重读位置互相接近），统一合并成了 des-。结果是一个法语 des- 背后可能藏着两个不同的拉丁前缀：

  • 拉丁 dēstruere → 古法语 destruire → 英语 destroy。这里的 des- 是 de-（向下）。
  • 拉丁 dishonorare → 古法语 deshonorer → 英语 dishonour。这里的 des- 是 dis-（否定）。

同一个 des-——一个是"往下拆"，一个是"不名誉"。当这两个词在 14 世纪同时出现在英语中时，没有英国人能看出它们的前缀不一样。直到 15 世纪学者开始恢复拉丁拼写时才发现问题。恢复结果：

  • des- 对应 de- → 恢复为 de-：destroy, defeat, delay, deserve
  • des- 对应 dis- → 恢复为 dis-：dishonour, discomfort, disfigure

但有一个例外确认了这个规则：despair。它的拉丁原文是 dēspērāre（de- + sperare = 从希望中脱离→绝望），经过法语变成了 despoir → despair。15 世纪学者认识到了它的 de- 来源（不是 dis-），但没有把它恢复为 *despair——因为 despair 的语义已经深深固化，而且发音已经走了太远，恢复拼写会让人不知道怎么念。despair 的拼写被留在了古法语阶段——一个没有被整容的幸存者。[Etym]

在英国 — 反转义的爆炸

文艺复兴后，de- 的"向下"和"彻底"义继续在借词中存活，但 19-20 世纪真正改变 de- 命运的是反转义的爆炸。

和 re- 一样，de- 在 19 世纪开始被英语使用者自由地贴到任何动词前面——表达的不是"向下"或"彻底"，而是"做的反操作"：

  • 1876：de-anglicize——让英语失去英语味
  • 1895：defrost——把霜去掉
  • 1903：devalue——把价值反过来
  • 1943：defuse——拆掉引信（比喻：化解紧张）
  • 1964：de-escalate——降低冲突等级

de- 成为了英语的"undo"前缀——re- 是再做一次，de- 是反着做一次。如果你建了一个文件（create），你可以重做（re-create = 重新建一个），也可以删除（delete = 把它的存在抹掉）。反着做的动作可以用 de- 来表达——这已经成为了 de- 在 21 世纪英语中的主要能产功能。

de- 在现代英语中的语义格局：物理向下（decline, decrease, depend）→ 离开/去除（depart, decide, defeat）→ 彻底做到底（deserve）→ 反转/解开（develop, detect, defrost, decode）。四条线，同一个从上往下的动作。最古老的义（向下）和最年轻的义（反转）共享同一个 de-——这就是六千年前 PIE 人刚才用手指了指下面的地方。[Etym]

③ 音变机制：de- 的零变体

de- 没有任何辅音同化变体。dē- 以长元音 ē 结尾，d 后面永远跟一个元音缓冲——不需要像 ad-（辅音 d 结尾、直接撞下一个辅音）那样发生同化。

表面形式 触发条件 机制 例词
de- 所有情况 — decide, depend, destroy

这是 de- 和 ad- 之间最重要的形式对比：ad- 的 d 是裸露在外的（ad- + capere → accept），de- 的 d 后面永远跟着一个 e 作为垫片。这额外的一个字母让 de- 经历了完全不同的命运——零变体。

⑤ 学术争议

  • *de- 的确切 PIE 语义：传统重建（Pokorny）把它列为"向下、从……离开"的空间小品词——和 ad-、ab- 并列。但 de Vaan（2008）强调它的指示代词语义基础（"这是指示词、不是介词"），认为"向下"的义项是拉丁语后期的创新——*de- 本身只是一个中性的指示手势，和 the/this 同源。这场争论对学习者有一个实际意义：如果 de- 确实是指示词出身，那么它和 to 的关系（同源但方向相反）就更加自然——同一个手势指不同的方向。[Wikt-PIE]
  • de- 和 dis- 在古法语中的合流程度：主流认为古法语 des- 是一个完整的合并——de- 和 dis- 在古法语中已经无法区分。但少数研究（如 Pope 1934）指出不同的法语方言可有不同的合并程度——北方方言 des- 倾向 dis-、南方倾向 de-。英语从诺曼法语（北方）借入的 des- 词更可能还原为 dis-，而后来从巴黎法语（中部）借入的 des- 词可能偏 de-。这可以部分解释为什么"des-" 的英语后代表现出不同的现代拼写。[Etym]
  • de- 反转义的年龄：传统观点认为 de- 的反转义是 19 世纪现代英语的创新。但 defame（14 世纪——de- + fama 名声→毁谤）和 deface（14 世纪——de- + face→破坏外观）的反转义在 14 世纪就已经出现。反转义不是现代英语的发明——它一直潜伏在 de- 的"往下走到底"语义线的末端——走到底 = 走到了原来状态的反面。只是 19 世纪的英语使用者把这个潜在的义项系统地激活了。[Etym]
