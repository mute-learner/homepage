② 叙事链

在 PIE — 源头：*per- 家族的四兄弟

六千年前，PIE 人有一个极其活跃的根词 *per-，意思是向前、穿过、从头到尾。这不是一个静止的方向——*per- 带有强烈的运动能量。一个人从起点出发，朝前走，穿过中间的一切障碍，最后到达另一头——整个过程就是 *per-。

*per- 是 PIE 中最高产的根之一。到古典时期它已经分裂成了几十个不同形式的后代，其中给英语留下最深刻印记的是四个前缀：

  • *prai-（*per- 的方位格）→ 拉丁 prae- → 英语 pre-。方位格的作用是标记一个东西所在的位置——*prai- 的意思是「在……的前面这个位置上」。不是走着的，是站着的——人已经在前面了。
  • *pro（*per- 的 o 级变体）→ 拉丁 pro- → 英语 pro-。o 级变体在 PIE 中用于标记主动和向外——*pro 强调的不再是位置而是方向——是从里向外的前动力。
  • *per-（保留原形）→ 拉丁 per- → 英语 per-。穿越到另一头——perfect = 彻底做好（per- + facere 做 = 做穿过去→做完了、做好了）。
  • *pr̥-（*per- 的零级）→ 原始日耳曼 *fur- → 古英语 fore- → 英语 fore-。零级丢了 e，r 变成音节的载体——日耳曼人从这个零级形式出发，发展出了和 pre- 几乎同义的日耳曼前缀。

pre-、pro-、per-、fore-——这四个前缀你每一个都认识，但你可能不知道它们是一家。preview = 提前看、proceed = 往前走、perfect = 彻底做好、foresee = 预见。四个人来自同一个 PIE 根词「向前」——只是各自走了不同的字形和语义方向。[Wikt-PIE]

在罗马 — 站在前面的人

罗马人继承了 *prai-，发展出拉丁语前缀 prae-（在……之前、在前面）。prae- 在拉丁语中三条线同时运行：

时间先到： praedicere（pre- + dicere 说）= 提前说出→ predict。罗马占卜官观看鸟的飞行路线（auspices = avis 鸟 + specere 看），然后 prae-dicere——在事情发生之前把鸟意说出。predict 的底层画面是古罗马祭司站在神殿前看着天空说话。

空间在前面： praesidere（pre- + sedere 坐）= 坐在前面→ preside（主持）→ president（坐在最前面的人）。罗马元老院中最高长官的座位在整个会场的正前方中央——prae-sedere 就是坐在那个特定的位置。美国总统的座位叫 Presidential，而 president 和 preside 的拉丁源头就是那个元老院的前排座椅。

优先/先手： praevenire（pre- + venire 来）= 提前来到→ prevent（预防）。罗马军事中 praevenire 是战术术语——在敌人到达战略要点之前你先到了。它的原始语义是「先发制人」——你来得比敌人快所以你赢了。现代英语 prevent 把「来了之后挡住对方」这后半段变成了主导义，前半段「先到」已经完全退了色。[Etym]

在希腊 — parallel 和不 parallel 的演化

PIE *per- 在希腊语中产生了两个前缀——都与 pre- 同源但走了不同的路：

para-（παρά = 在旁边、沿着）。来自 *per- 的一个带后缀的变体——*per- + -a（方向后缀）→ *para-（在前进方向的一侧→在旁边）。paradox（para- 在旁边+ doxa 意见 = 在正统意见旁边的→自相矛盾的）、parallel（para- 旁边 + allēlos 互相 = 在彼此旁边并排的→平行的）。

peri-（περί = 围绕、附近）。来自 *per- 的另一个带后缀形式——*peri-。perimeter（peri- 围绕 + metron 测量 = 围绕一圈量→周长）、period（peri- 围绕 + hodos 路 = 绕完一圈→周期）。

para- 和 peri- 都没有 pre- 的「在前面」义——它们从 *per- 取了「在……旁边」和「围绕」两个侧面的含义。pre- 的「前面」义是 *prai- 方位格特有的——只有拉丁人保持了它。[Etym]

在日耳曼 — fore-：pre- 在家里的弟弟

PIE *per- 在日耳曼语中演化出了 fore- 前缀——它是 pre- 的日耳曼表亲，义几乎完全相同。古英语 fore-（在……之前）→ 现代英语 fore-：

  • foresee = fore- + see = 看到前面→预见 = predict
  • foretell = fore- + tell = 提前告诉→预言 = predict
  • forehead = fore- + head = 头的正面→前额
  • foreword = fore- + word = 在前面的话→前言 = preface

pre- 和 fore- 几乎是完美同义——preview / foresee、preface / foreword。唯一的区别是语域：pre- 偏学术和拉丁层，fore- 偏日常和日耳曼层。prevent 没有对应的 fore- 词——因为 prevent 的「阻挡」语义是拉丁特有的演化线，日耳曼人没有走这条路。

还有一个广为人知的日耳曼后代：for——介词 for 也是从 *per- 来的（*per- → PGmc *fur → OE for）。for 走了最抽象的路——从空间方向演变成了目的/受益标记。你做一件事 for someone = 你的动作朝那个人去了——*per-「向前」的底层方向感还在。[Etym]

在法国 — 平稳传承

拉丁 prae- → 古法语 pre-，几乎零变形——原因是 prae- 和 pre- 的发音变化极小（ae → e 是常规的元音简化），只有一个元音变了。这和 ad- → a-（辅音直接被削）形成了鲜明对比。pre- 保守的拼写帮助它在英语中保持了透明度和能产性。[Etym]

在英国 — 超级能产的现代 pre-

pre- 在现代英语中具备了和 re- 相似的能产性——它可以自由地贴到任何名词或动词前面表示「提前、预先」：

  • pre-order（预订）——在商品正式发售前下单
  • pre-game（赛前）——比赛开始前的活动或分析
  • pre-screen（预筛）——在正式面试或放映前先筛选
  • pre-existing（预先存在的）——在某个时间点之前已经存在的

pre- 比 ante-（另一个表示"前面"的拉丁前缀）更有活力，因为 pre- 没有标记为纯粹的古典词——它短（三个字母）、发音简单、义明确。一个 21 世纪的英语使用者发明一个新的 pre- 词不需要经过任何人的批准——pre- 是英语自己的前缀了。[Etym]

③ 音变机制：pre- 的零变体

pre- 没有任何辅音同化变体。p-r-e 中的 e 是末尾元音，作为 p 和后接辅音之间的缓冲——不需要像 ad- 那样将辅音（d）与后接辅音同化。此外，pre- 唯一露在外面的辅音是 r——流音——流音在任何后继辅音前面都能和平共处。

⑤ 学术争议

  • prae- 和 pro- 在拉丁语中的语义重叠：在古典拉丁语中 prae-（在前面）和 pro-（向前）有清晰的语义区分——但在晚期拉丁语中两者开始重叠。de Vaan（2008）认为这种重叠加速了 prae- 在罗曼语族中的衰退——法语 pre- 幸存但数量有限，西班牙语和意大利语中 pre- 已几乎不产新词。英语继承了 prae- 但通过学术借词绕过了罗曼语的自然衰退——pre- 在英语中反而在 19-20 世纪恢复了能产性。[Etym]
  • *per- 家族的规模争议：*per- 是 PIE 中最高产但也最"模糊"的根之一。Pokorny 在 1959 年的 IEW 中把几乎所有以 p-r 开头的都归到了 *per- 下。但 Rix（LIV² 2001）把许多之前归入 *per- 的词重新分配给了不同的根（如 *perd-「放屁」、*prek-「请求」）。现代共识是 *per- 家族确实巨大——但与 Pokorny 列的相比缩小了大约三分之一。对学习者来说：pre-、pro-、per-、fore- 四人同源是确定的——不必被专家缩减三分之一的事干扰。[Wikt-PIE]
