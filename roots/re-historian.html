② 叙事链

在 PIE — 源头：转身

六千年前，当一个 PIE 人说 *wert- 的时候，他在描述这样一个画面：一个人或一个东西绕着中心点转动——不是在直线上移动，而是在弧线上改变方向。

*wert- 是一个动词词根——它描述的是一个动作，不是一个位置。PIE 的所有前缀（ad- 朝向、ab- 离开、con- 一起、dis- 分开）都来自小品词——不描述动作的词，只描述方向和空间关系。但 *wert- 不同——它本身就是一个完整的动作动词，描述的是物体绕轴旋转。六千年后，这个词根的一个变体 *wret-（字母 r 和 w 换了位置——这在语言中叫做异位 metathesis，和 ask/aks 或者 pretty/purty 同类现象）进入了拉丁语，成了一个前缀。[Wikt-PIE]

*wert- 不是前缀——它最初不贴到别的动词前。它的意思就是「转」。但 *wret- 这个变体从动词分化出来，意义被抽象化：不再描述旋转的动作，而是描述旋转后的结果方向——「转完了面对的那一面」→「后面的那一面」→「回头」。一个动词变成方向标记——这是语法史上最高效的作弊之一。

*wert- 的后代在英语中无处不在：verse（转行→诗句）、convert（彻底转→改变/皈依）、versus（转向对面→对抗→vs）、invert（往里面转→倒转）、divorce（转向分开→离婚）。每六个英语常用词就有一个来自 *wert-。re- 只是这个大家族里选择了走"简化成前缀"路线的那一支。而它的日耳曼兄弟走的是完全不同的路：古英语 -weard（转向→……的方向）→ 现代英语 -ward。forward = 朝前转，backward = 朝后转。同一个 PIE 根，拉丁人把它简化成一个两字母前缀，日耳曼人把它做成了英语最常用的方向后缀。[Wikt-PIE][Etym]

在罗马 — 三个义面的转身

罗马人继承了 PIE *wret- 的简化形，发展出拉丁语前缀 re-——一个三义面同时运行的超级前缀。

与 dis- 的三义面不同，re- 的三义面不是平行发展——它们是从同一个身体动作自然衍生出来的：

线一：回——转身后朝来的方向走。 这是最原始的空间义。拉丁语中：

  • re-vertere = re- + vertere（转）→ 双重"转"——转回去（return）。vertere 和 re- 来自同一个 PIE 根——return 就是"转转"——两个"转"叠在一起。
  • re-cipere = re- + capere（拿）→ 拿回来（receive）。画面是一个人伸出手去接住从远处传回来的东西——re- 不强调「自己拿到」的结果，而强调物件从远处回到了自己手里的过程。
  • re-movēre = re- + movēre（移动）→ 移回去（remove）。移动的方向是反向的——不是往前推，而是往后拉。

线二：再——转一圈又回到了原点。 这是空间→时间的隐喻映射。身体转一圈回到原位 = 动作做完又再做一次：

  • re-petere = re- + petere（寻求）→ 再次寻求（repeat）。petere 不是被动的"要求"——它带着「冲着目标去」的主动意味。repeat 的字面画面是你第一次去要没要到，或者要到之后又重新跑去要。

线三：对抗——转身面对后面的方向。 转身后你面对的方向和原来相反：

  • re-sistere = re- + sistere（站立）→ 转身站立面对（resist）。sistere 是 stare（站立）的使动形式——「自己站着」是 stare，「让别人或自己站住」是 sistere。resist 的字面义就是「让你自己站住去面对从后面来的人/力」。
  • re-bellare = re- + bellum（战争）→ 对已经统治你的人重新开战（rebel）。bellum 和 bell-（美丽）是同音不同源的两个拉丁词——杜鲁门 Capote 曾经开玩笑说 rebella 意味着"重新变美"，这是完全错误的——rebel 里的 bell- 是战争，不是美丽。

这三种意义在拉丁语中同时活跃——不需要哪个先来后到，因为它们在物理上是可以同时发生的：你转身 = 回头 = 面对反方向 = 再转一圈回到原点。这个动作的四重结果被拉丁人拆成了三个语义格，六千年后的英语中依然完整保留。[Etym]

red- 变体：在元音前，re- 变成 red-。这不是辅音同化（像 con- 在 l/r 前变成 col-/cor-）——re- 只有一个辅音 r，不存在被同化的对象。red- 的 d 是一个插入的过渡音，避免 r 和下一个元音在发音上直接碰撞：rē- + emere → rēdemere → redeem。这和 sē- + ire → sēd-itio（sedition）是同一个机制。今天仍然存在的 red- 词极为罕见——redeem、redact、redolent、redundant——屈指可数。许多拉丁语中带 red- 的词到了英语后 d 被丢掉（re-emere → redeem 保留了 d，但 re-agere → reagere 的 d 在进入英语之前就已经消失了）。[Etym]

在希腊 — 无

PIE *wert- 在希腊语中有后代词（rhaibos = 弯曲的），但没有发展成前缀。希腊人表达「回/再」使用的系统不同——ana-（向上/再次——anatomy = 向上切开→解剖、anagram = 重新排列的字母）和 palin-（再次→ palindrome = 回文）。ana- 和 re- 在义项上部分重叠（都可表示"再"），但它们来自完全不同的 PIE 根——ana- 来自 *h₂en-（向上），re- 来自 *wert-（转）。学习者在学 ana- 和 re- 时不要被它们重合的义项欺骗——它们是远亲不如不同的两个陌生人。[Etym]

在日耳曼 — -ward 和 worth：re- 在英语里的血亲

这是 re- 故事里对学习者最有用的部分——而且大多数人在学英语时从来没被告知。

PIE *wert- 进入原始日耳曼语，没有变成前缀——而是发展出了两个你每天都在用的东西：

-ward（方向后缀）。古英语 -weard（转向某个方向）→ 现代英语 -ward：forward（朝前方）、backward（朝后方）、inward（朝内部）、outward（朝外部）。方向和运动的后缀——-ward 就是转了身之后朝的方向。re- 和 -ward 来自同一个 PIE 动词：-ward 是转身后朝的方向，re- 是把动作转回去。两者碰面的最好例子：re-ward = 向你转回来 → 回报（re- 的回 + ward 的朝向，双重"转"）。reward 不是 re- 和一个神秘词根的拼合——它是 re- 和自己的日耳曼表亲 -ward 联手造出来的！

worth（价值）。古英语 weorþ（价值）→ 现代英语 worth。语义路径：转 → 转向对等物 → 等价交换 → 价值。在原始日耳曼文化中，商品以物易物时就靠「转向」来表示对等——一个东西转向另一个东西，它俩等价。worth 是把这种交换关系名词化的结果。同一个 PIE "转"也变成了 werðan（变成）——「转向某状态→变成」——古英语 "weorðan" 兼表「变成」和「价值」，两个语义还未分化。现代英语把"变成"的义项完全放弃了（被 become 取代），只留下 worth。re-、-ward、worth、verse——四个词看起来毫无关系，但六千年前它们都是"转"。[Etym]

在法国 — 强化而非改变

诺曼征服后，re- 词大量进入英语——但与其他前缀不同，re- 的词在法语中没有发生剧烈的拼写变形。拉丁 re- → 古法语 re- → 中古英语 re-，一路顺风——因为 re- 本身已经短到极点（两个字母 r-e），古法语没有可磨掉的辅音（不像 ad- → a-，dis- → des-）。

法语给 re- 注入的不是变形，而是量。在 11-14 世纪期间，英语通过数百个法语和拉丁借词吸收了 re- 前缀。这一波大量涌入的结果是 re- 成为了英语中最常见的外来前缀之一。到 14 世纪，英语使用者已经完全把 re- 当成自己语言的一部分——re- 开始被贴到英语本土日耳曼词根上：[Etym]

  • 古英语 writan（写）+ re- → rewrite
  • 古英语 byldan（建）+ re- → rebuild
  • 古英语 fyllan（填）+ re- → refill

re- 是少数几个从一开始就成功跨过了"只能接拉丁词"这条线的拉丁前缀。un- 和 dis- 也跨过了——但 re- 跨得最远。[Etym]

在英国 — 疯狂能产

文艺复兴后，re- 的生产力爆炸式增长。到 18-20 世纪，re- 已经完全不再被视为外来前缀——它和 un- 并列为英语中最能产的两个前缀：

  • 17 世纪：re-animate（复生）、re-assemble（重组）、re-examine（复检）
  • 18 世纪：re-arrange（重排）、re-elect（重选）、re-apply（重请）
  • 19 世纪：re-energize（充电）、re-educate（重教）、re-align（重排）
  • 20 世纪：reboot（重启电脑）、rethink（重新思考）、repackage（重包装）
  • 21 世纪：regram（转帖到 Instagram）、reblog（重新转发博客）—— re- 已经可以接到商标和新词上面

re- 是英语前缀中能产性最高的——没有之一。OED（牛津英语大词典）评论说 re- 作为形成元素「实际上是无限的」——任何英语动词都可加上 re-。re- 是现代英语自己的前缀，不再是拉丁人的专利。

re- 在现代英语中的语义格局：回（return、retreat、release、redeem）→ 再（rethink、rewrite、repeat、revise）→ 对抗（resist、rebel）。三条线，同一个转身动作。最日常的词和最学术的词：return 和 redeem 的 re- 是同一个意思。你每天说 return ——那个 re- 就是六千年前 PIE 人转身时脑子里转的那条弧线。[Etym]

③ 音变机制：re- 的（几乎）零变体

re- 没有辅音同化变体。原因简单：re- 只有一个辅音 -r，而 r 是流音——和元音一样灵活，可以和任何辅音和平共处。

表面形式 触发条件 机制 例词
re- 默认 — return, repeat, resist
red- 元音前（极少数） 插入 -d 避免 re- 和元音直接碰撞 redeem, redact

流音 r 不需要像塞音（ad- 的 d、ab- 的 b）那样精确配合爆破位置的发音器官配置——r 在任何位置都可以流出气流，所以永远不会和下一个辅音发生冲突。这是 re- 只有一个变体的发音生理原因。

red- 的 -d 和 sēd- 的 -d 是同一个东西——拉丁人对两个元音直接相邻有近乎恐惧的回避。re-emere → rēdemere——中间必须塞一个辅音。

⑤ 学术争议

  • re- 的 PIE 重建争议：Watkins（2000）认为 re- 来自 PIE *wret-（*wert- 的异位变体），但 De Vaan（2004）主张来自 PIE *ure（向后）。De Vaan 的证据在于 re- 在拉丁语中没有任何 w- 的痕迹（如果来自 *wret-，拉丁语应该出现 vret- 或类似形式）。但 Watkins 的反驳是 *wret- 在进入拉丁语之前的意大利语族阶段就已经丢失了 w——这恰恰说明它是一个古老的简化。共识是：两个假说都缺乏决定性证据，但对学习者来说无关紧要——re- 在拉丁语和英语中的语义轨迹是清晰而无可争议的。[Etym][Wikt-PIE]
  • red- 变体的确切动机：主流认为 red- 的 d 是插入的过渡辅音（和 sēd- 机制相同）。但 Paul（1908）主张 red- 可能来自另一个 PIE 小品词 *ed-（向外）与 re- 的复合——这条线后来被多数词源学家否定了，但在较老旧的词典中偶尔可见。[Wikt-Lat]
  • re- 的生产力上限：re- 的能产性在理论上没有限制——为什么英语使用者没有把 re- 贴到所有动词上？只有一个原因：歧义。recover（恢复）和 re-cover（重新覆盖）是靠连字符区分的。recreate（消遣放松）和 re-create（重新创造）同理。如果 re- 的"再"义太泛滥，会产生大量歧义词——所以英语实际使用中会自我限制。这是一个语言自我调控的例子——语言不是越能产越好，歧义是一个内置刹车。[Etym]
